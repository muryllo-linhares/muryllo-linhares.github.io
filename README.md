Atria

Landing page de apresentação do projeto Atria, desenvolvida para a atividade de Identidade Visual e Landing Page (Programação Web III).

Sobre o projeto

A Atria é uma plataforma de aprendizado de idiomas baseada em flashcards, com gamificação (pontuação e streak de estudo) e um dispositivo físico próprio construído com ESP32 para revisão sem depender do celular. Também é o projeto de TCC do Técnico em Desenvolvimento de Sistemas.

Problema e solução

Problema: flashcards de papel se perdem, não guardam histórico de revisão e não geram nenhum incentivo para manter a rotina de estudo, o que atrapalha principalmente estudantes do técnico/ensino médio e vestibulandos.

Solução: a Atria digitaliza o flashcard, guarda o histórico de revisões, soma pontos e mantém uma sequência de dias estudados (streak), permite importar baralhos do Anki e ainda oferece um dispositivo físico (ESP32) para revisar sem precisar do celular.
